# 🍉 Fruit Ninja – Vue.js Edition  

A fun, browser-based recreation of **Fruit Ninja**, built using **Vue 3** and **Vuex**.  
Slice fruits, dodge bombs, and master all 3 juicy levels! ⚔️🍍  

---

## 🎯 Features  

### 🕹️ Gameplay  
- **3 Levels of increasing challenge**  
  - Level 1 – Learn to slice, no bombs!  
  - Level 2 – Faster fruit + bombs 💣  
  - Level 3 – Chaos mode: fast fruit, 1 life, and special fruits 🍍  

### 💫 Special Fruits  
- 💙 **Slow Motion Fruit** – Slows time for 5 seconds.  
- 💛 **Life Fruit** – Adds an extra life.  

### 🌈 Visuals & UI  
- Animated **start screen** with pineapple-split effect.  
- Custom **cursor blade**.  
- Confetti celebration when you win 🎉  
- Responsive, colorful, and arcade-style visuals.  

---

| Tech | Purpose |
|------|----------|
